# Marauder UI (Marauder Desk)

JASON Studio · 为 Waveshare ESP32-C5-WIFI6-KIT-N32R8-U 和 Seeed Studio XIAO ESP32-C5 的 JMOD 固件制作的本地仪表盘。

Waveshare 支持原生 USB 和可选 UART 双线连接；XIAO 只使用一个原生 USB 端点，不进行 UART 高波特率协商。两种板型按各自构建标识核验，不能混刷更新包。

## 使用

1. 开发板接 **USB** 或 **UART** 口，断开占用该端口的其他串口网页或终端。双线模式由后端显式绑定，见 Host_Connection 文档。
2. 双击同目录的 **启动.command**，保留打开的终端窗口。
3. 打开 <http://127.0.0.1:8765>，点击「连接设备」，再「开始采集」。

服务正在运行时，再次双击启动文件只会打开现有仪表盘。关闭服务使用终端中的 Control+C；正常关闭会尝试停止采集并释放串口。网页刷新不会重新打开串口，也不会中断任务。关闭网页后，已启动的任务仍会运行到设定时长，随后由本机服务停止。

当前固件在原生 USB 和 UART 口保留 CLI；协商后的端口由 Host_Connection 独占。不要同时用旧网页、screen 或 miniterm 打开同一端口。连接错误中会列出已占用目标串口的进程 PID；程序不会杀掉进程。USB 路径变化后在设置中刷新设备列表；拔插后点击连接重新核验，不自动恢复采集。

## 页面

- **设备概览**：真实芯片温度、CPU 频率、内存、PSRAM、文件系统和运行时间；可在设置全局关闭。
- **WLAN 概览**：BSSID 去重 AP 数量、双频分类、最近采样信号、AP 记录速率、信道分布和最近发现。
- **网络观察**：搜索、频段过滤、按需展开 BSSID / 采样时间 / RSSI 历史、终端关联、JSON 导出。终端视图排除固件可能输出的组播 / 广播目的地址。
- **蓝牙**：被动 BLE 广播发现、RSSI 历史和广播详情，独立的隐藏掉线设备开关。
- **文件**：内部 LittleFS 的目录、下载、新建目录、重命名和可恢复回收站。
- **控制台**：右下角悬停展开，点击固定，可放大；原始双向日志、跟随输出、日志导出；单行 CLI 命令连同参数直接转发给固件，不限制命令名称。输入第一个词时按前缀弹出候选；空输入框按 ↑/↓ 展开全部命令（分别选中第一项/最后一项）；空格后按固件 `help` 语法逐级显示子命令、固定选项与枚举值。↑/↓ 选择、Tab 补全后继续下一级、Esc 收起；参数值只显示语法提示，不自动填写。空间不足时前面的命令路径折叠为 …，保留最后一个词和语法，完整内容可悬停查看。候选右侧显示已核验的简短注释，未知项留空，小屏隐藏；依据见 [注释来源](docs/completion-notes.md)。固件决定各命令是否可用，补全列表不作为白名单。发送手动命令后关闭仪表盘自动计时/分轮调度，避免额外 stopscan 或详情查询插入操作；用 stopscan 或“结束手动控制”返回空闲状态。
- **设置**：串口选择、实时推送或轮询、250–60000 ms 自定义间隔、浅色 / 深色 / 系统主题。显示偏好保存在此浏览器；「设备概览」开关由本机服务全局保存，对所有订阅端生效。

Beacon 模式持续输出信号样本。AP + STA 使用 `scanall`，每 30 秒形成一个观察轮次。由于固件只上报新条目，本机服务会在停止采集后，用 `clearlist -a` 刷新固件中的临时 AP / STA 列表，然后开始下一轮；不会修改 Flash、保存的 SSID 或网络配置。查询到的列表索引仅在当前轮次有效。

“隐藏掉线设备”立即保存。连续两个合格轮次未收到某个 AP / STA 的记录后，开启开关时从列表、计数、信道分布和导出中排除；关闭时保留并灰显。采集中不因静默时间到期删除旧记录。中止、串口中断或过短的轮次不会增加缺失次数；停止采集后不会继续按时间老化。Beacon 只对本轮实际收到记录的信道更新 AP 缺失状态，不推断其他信道或 STA 掉线。灰色不等同于确认断电，弱信号或漏报也可能造成连续未发现。

已有行不会跟随 RSSI 波动重新排序。正在展开或聚焦的详情会保留到收起，即使该 AP 已从统计中排除；原始控制台日志始终保留。清空观察记录只清空本机工作区。

**数据解释**：信道分布是本次工作区已观察 AP 的数量，不是频谱占用率；每秒记录数不是空中总包数或网速。RSSI 是最后一次收到的采样，不承诺未扫描期间仍实时有效。详情提供最后出现时间。设备概览中的 PSRAM 来自 `deviceinfo` 的当前采样；设置页保留启动日志中的容量，并标为启动值。不能取得的能力字段不填假值；GPS 是此 USB 构建的禁用配置。

## 本地托管

前端为原生 HTML/CSS/JS，无 npm、构建步骤、CDN、远程字体或运行时外部请求。Python 本机服务独占串口，用 SSE 推送数据，轮询只读取本机状态快照，不轮番向固件发送查询。

可使用 Python 3.10+ 创建项目独立环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

指定端口：

```sh
.venv/bin/python server.py --port 8766
```

需要使用 Python 服务，不能只双击 HTML，也不能只把静态文件交给普通静态服务器。仅监听 `127.0.0.1`；无需云服务、浏览器 Web Serial 授权或 ESP32 内建 HTTP 服务。本包没有提供局域网 / 公网暴露方式。

连接不切换 DTR/RTS，不隐式停止扫描。先读取能力，支持时显式协商 Host_Connection，否则继续使用普通 CLI。重新连接时读取现有活动状态；不自动重启无线任务。操作系统重枚举或用户按键仍可能复位设备。

## 兼容性与实现

支持以 Marauder **v1.18.0**、Arduino-ESP32 **3.3.6** 为基础的两个 JMOD 板型：`waveshare-c5-rgb-usb-4m6m-v1` 与 `xiao-c5-usb-3m1664k-v1`。均使用内部存储，默认不启用 GPS。未知或不匹配的板型会被拒绝连接。

- 一条串口读取循环和串行命令队列；有读写超时、目标端口占用检查和异常释放。
- 启动采集前先 stopscan，并等待固件确认；定时停止独立于网页运行。多轮任务中的读取详情 / 切换间隙补回采集时长。
- 服务重启会更换实例 ID，避免网页把新的状态误当成过期快照；SSE 断开时按设置进行轮询补偿。
- 解析 C5 当前 Beacon / scanall 输出，scanall 两个末尾能力字节只在该模式下剥离；同名 SSID 按不同 BSSID 区分。
- 日志最多 1000 行、每个 AP 最多 60 个历史采样、AP/STA 分别最多 2000 条，状态变化合并推送最多每秒 20 次，无变化时仅每 2 秒发送保活注释。多开页面共享同一个串口服务。
- 观察表保留在本机服务内存；文件下载和实时捕获使用后端私有临时目录。服务退出会清空观察工作区。没有上传、遥测或分析服务。
- API 校验 Host、Origin、会话令牌；不开放跨域请求。串口内容以文本显示，SSID 不作为 HTML 执行。静态文件使用固定白名单。
- WebUI 服务本身不刷写固件；本次内部存储固件的刷写与备份另见固件目录的 INTERNAL-STORAGE.md。

## 远程访问

开发板仍通过 USB 连接运行服务的主机。浏览器可以在另一台电脑，通过 SSH 本地端口转发访问本机服务，不需要把 8765 端口暴露到公网。例如，在远程操作的电脑运行（替换 Mac 地址）：

```sh
ssh -N -L 8765:127.0.0.1:8765 user@HOST
```

然后在那台电脑打开 http://127.0.0.1:8765 。前提是到 Mac 的 SSH 连接已由你配置好。SSH 服务及端口转发需由操作者配置。当前固件没有提供本 Dashboard 所需的无线网络接口。

## AP 详情

AP + STA 每轮结束后，从设备缓存读取 `list -a`，用有事务 ID 的 `protocolinfo` 确认列表输出结束，再按有效索引读取 `info -a <index>`。详情最终按 **BSSID** 匹配，不按 SSID 或推测索引匹配；收到整条 Security 结束字段后才提交。读取有总时间预算，缺失字段不会伪造。Beacon 模式本身不建立同样的设备缓存，新发现网络可能没有安全协议字段；AP + STA 是默认模式。

展开内容包含：BSSID / MAC、安全协议、信道、中心频率、频段、RSSI、品牌（有数据时）、帧计数、关联数量、完整 EAPOL 标志、原始能力标记、MAC 地址类型、观察样本和首末接收时间。中心频率按信道推导，帧计数等遵循固件统计口径。

WPA 信息来自固件对 Beacon 的 RSN / WPA IE 解析，**无需连接或主动协商**。没有增加连接或协商开关，也未发送 Deauth 或其他攻击命令。当前 CLI 不导出完整的 AKM / cipher 列表、PMF、带宽、完整 PHY 能力及 WPS 字段，因此没有将这些字段凭空补齐；WPA2/WPA3 过渡模式等精细分类受固件解析器限制。

页面仅显示控件、状态和数据，不再显示辅助解释小字。使用解释保留在本文档中。


## AP + STA + Beacon

新增独立的 `scancombined` 模式，网页采集模式选择 **AP + STA + Beacon**。原有 AP + STA 与 Beacon 模式、回调与跳频策略保持不变。新模式使用相同的跳频间隔，被动同时解析 Beacon 与基础设施数据帧；不关联 AP、不发探测请求、不执行攻击。Waveshare 扫描灯使用青白色 `#80FFFF`，驱动使用 NEO_RGB；XIAO 使用单色黄色灯。EnableLED 设置控制所有状态指示。

新模式在回调中将有界解码结果放入非阻塞队列，由主循环更新固定容量的 PSRAM 表，每设备最多每秒上报一次合并结果。新模式按当前 HWCDC 驱动的方式重新触发待发 USB 数据的中断，不等待或清空队列，不更改串口超时或原有模式。原始接收次数保存在计数中，不等于串口输出行数。AP 名称以十六进制传输，避免名称中的引号或换行破坏协议；网页按 UTF-8 显示。SSID、安全类型、能力字节直接从 Beacon 解析；终端关系只按明确的 ToDS/FromDS 数据帧识别，排除组播地址和 WDS，表示观察到的关系而非实时在线证明。没有额外握手、协商或定期停扫查询。

网页每 30 秒仅结算观察窗口，不向新模式发送停扫、清列表或重启命令；连续两轮未观察到才按隐藏开关处理。设备状态输出中断或固定表溢出时，不凭不完整结果判断掉线。接收队列 128 条，固定表共 1024 个 AP/STA 条目，最多 32 次哈希探测；溢出计数通过状态协议报告。射频仍只能逐信道监听，不能保证发现全部弱信号设备。

串口命令：`scancombined` 开始，`stopscan` 停止。能力标记为 `discovery-v1`。旧固件不支持该模式时，服务会拒绝启动该选项。固件源码位于仓库的 `esp32_marauder/`，网页及本机服务位于 `Marauder-UI/`。

兼容的本板更新包现在可通过固件目录的 `更新固件.command` 使用 USB 双槽更新，保留本模式、校准和数据。旧的仅 USB CDC 补丁升级脚本仍不适用；分区迁移及升级边界见 [USB-OTA.md](../USB-OTA.md)。

## 事件驱动与多端订阅（2026-10-10）

串口由一个后台线程独占，读取使用非阻塞模式及 select；命令入队后通过 socketpair 唤醒线程，不等待固定轮询周期。多个网页或后台程序可同时订阅 `GET /api/events`，或读取 `GET /api/status?since=<日志游标>`；这些只读请求不会向开发板发命令。每个 SSE 客户端独立发送，网络写入不持有共享状态锁。断线重连可用 `since` 获取仍在 1000 行缓存中的日志；这不是无限历史存储。

写命令仍走原有带会话令牌的 API，由同一有界队列依次写入串口。一个请求表示发送一个完整命令，不保证跨多个请求的操作事务，也不允许两个程序直接打开物理串口。队列满会拒绝新请求。SSE 最多每秒 20 次用于合并密集更新，并非承诺 50 ms 以内完成固件命令；固件主循环、Flash 写入与 USB 调度仍影响响应。

保留轮询间隔设置和断线轮询补偿；远程连接继续使用已有 SSH 转发方式，没有开放新的网络监听地址。

设备概览的采样、零 USB 查询开关、BLE 运行边界及浮窗尺寸详见 [设备仪表盘说明](docs/device-dashboard.md)。

文件操作、传输校验和蓝牙在线判定详见 [文件管理说明](docs/file-manager.md)。

## Host_Connection

[协议、二进制 API、双 USB、恢复和验证](docs/Host_Connection.md)。普通 CLI、命令预测、文件页面与现有扫描选项保留。原始文件/捕获数据不经过 SSE、JSON 或控制台。协议已连接且空闲时，Waveshare RGB 常亮白色，XIAO 黄灯常亮；未连接时 XIAO 黄灯以一秒亮、一秒灭慢闪。

## 电脑端临时目录

设置 → 当前工作区 → 电脑端临时目录，可填写绝对路径或 `~/` 路径。保存后立即用于新建 PCAP 和设备文件下载；保存在本机 `.desk-settings.json`，重启仍有效。「系统默认」恢复系统临时目录。修改目录无需连接设备，也不会向 USB 发送命令。

每次服务启动或切换父目录会建立一个权限为 0700 的 `marauder-host-connection-*` 私有子目录，避免改动所选父目录的权限或混入其他文件。已有文件保留在原路径，当前服务中已完成文件的下载仍可使用；不自动迁移或清理旧目录。捕获或文件传输仍在运行/收尾时拒绝切换。无法写入会明确报错，不会静默改用系统目录。只删除本服务新建且为空的子目录。

命令行也可用 `python server.py --temp-dir ./.cache` 临时覆盖保存的设置。命令行覆盖本身不改写设置；在网页中点击保存才持久化。服务中端点仍各自只有一个串口所有者。
